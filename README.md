# homebrew-tap

Personal Homebrew tap for [@jmanuelrosa](https://github.com/jmanuelrosa)'s macOS apps.

## Install

```sh
brew install --cask jmanuelrosa/tap/<cask>
```

That single command auto-resolves `jmanuelrosa/tap` to this repo, adds the tap, and installs the cask. Updates land via `brew upgrade --cask <cask>`.

## Casks

| Cask | What it does | Source |
|------|--------------|--------|
| [`triage`](Casks/triage.rb) | Rule-based URL & Chrome profile router for macOS — YAML-configured, never asks. | [jmanuelrosa/triage](https://github.com/jmanuelrosa/triage) |

## Issues

Cask-install or update problems belong here. Bugs in the apps themselves belong in the linked source repo.
